# Data tables (Excel)

The data tables of the MRL8996 genome paper that are not distributed with the manuscript.
Data File 1-12 are the twelve tables previously supplied as a supplementary workbook, exported sheet by sheet without changes;
they are cited in the manuscript as Data File 1 to Data File 12. The same tables are in the figshare record of the study.

| File | Content |
|---|---|
| `Data_File_01_additional_assembly_statistics.xlsx` | Data File 1. Additional assembly statistics of MRL8996 |
| `Data_File_02_identity_matrix_MRL8996_vs_Fol4287.xlsx` | Data File 2. Matrix of identity between MRL8996 and Fol4287 |
| `Data_File_03_identity_matrix_MRL8996_vs_Fo47.xlsx` | Data File 3. Matrix of identity between MRL8996 and Fo47 |
| `Data_File_04_identity_matrix_MRL8996_self.xlsx` | Data File 4. Matrix of identity of MRL8996 against itself |
| `Data_File_05_structural_family_distribution.xlsx` | Data File 5. Distribution of the structural protein families (TM-score) and number of members |
| `Data_File_06_structural_network_nodes.xlsx` | Data File 6. Structural network nodes of the MRL8996 effector structures (submitted version) |
| `Data_File_07_repeat_statistics_per_chromosome.xlsx` | Data File 7. Repeat statistics per chromosome |
| `Data_File_08_SignalP_results.xlsx` | Data File 8. SignalP v6.0 results for the predicted secreted proteins |
| `Data_File_09_EffectorP_results.xlsx` | Data File 9. EffectorP v3.0 results |
| `Data_File_10_DeepTMHMM_results.xlsx` | Data File 10. DeepTMHMM results on the effector candidates |
| `Data_File_11_TM_score_all_vs_all.xlsx` | Data File 11. All-versus-all TM-scores of the AlphaFold2 models (1,006,071 pairs) |
| `Data_File_12_AMAPEC_predictions.xlsx` | Data File 12. AMAPEC antimicrobial-activity predictions with pLDDT |
| `Structural_network_MRL8996.xlsx` | Latest structural similarity network (482 nodes, including the 131 singletons): per-protein network family, closest known fold of the family and best PDB hit, and whether the protein is unique to MRL8996 in the three-way CD-HIT comparison; per-family fold assignment and fraction of MRL8996-unique members; column definitions in the README sheet |
